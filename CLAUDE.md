This repo is worked on from more than one computer, so all project context lives
here instead of in any assistant's local memory.

- Read `README.md` (what the project is) and `docs/ROADMAP.md` (phases, pending
  tasks and decisions taken) before doing anything.

  commit, so the next session — on any machine — starts with up-to-date context.
