# v1.4.0 — setup with nothing to edit, compare the commits of a pull request

## What's new since v1.3.0

**Setup with nothing to edit**
- `project-dir` is optional: the action finds the only `.kicad_pro` in the repository, at the root or in a subfolder. A board repository needs one workflow file and no options
- Quickstart in the README: add one file, wait for the run, turn on the portal
- When GitHub Pages is not serving the portal, the report links to the Pages settings and names the branch to choose
- Manual: new section 9, the whole flow with GitHub Desktop and no command line

**Design portal**
- Compare the commits of a pull request with each other, and pick them on the activity graph

**Fixes**
- Containers run with a UTF-8 locale: netclasses with non-ASCII names were checked with another class's clearance, which gave DRC errors a local DRC did not show
- The report detects that Pages is off even when the token cannot read the setting
- Re-running a pull request job no longer fails on the images branch
- Less noise in the report, from the first real use on a board

Users pinned to `@v1` get this automatically.

**Full changelog**: https://github.com/JMcordobamendez/kicad-hub/compare/v1.3.0...v1.4.0
